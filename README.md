# Battle Royale Mini — AndroidIDE

مشروع تجريبي أصلي ثنائي الأبعاد مستوحى من أسلوب ألعاب البقاء (ليس نسخة من Free Fire ولا يحتوي على ملفاتها أو علامتها).

## المميزات
- منظور علوي وخريطة صغيرة.
- تحكم بالحركة من الجهة اليسرى.
- زر إطلاق من الجهة اليمنى.
- خصوم يتحركون نحو اللاعب.
- نقاط/إقصاءات، ذخيرة وصحة.
- منطقة آمنة تتقلص تدريجياً.
- يعمل دون إنترنت ولا يحتاج API.

## فتح المشروع على الهاتف
1. فك ضغط الملف.
2. افتح AndroidIDE.
3. اختر Open Project وافتح مجلد `BattleRoyale_AndroidIDE`.
4. انتظر مزامنة Gradle ثم اضغط Run لبناء وتثبيت التطبيق.

## ملاحظات
- هذا نموذج أولي 2D قابل للتطوير، وليس لعبة 3D كاملة بمستوى Free Fire.
- يحتاج AndroidIDE إلى اتصال إنترنت أول مرة لتنزيل Gradle وAndroid Gradle Plugin وAndroid SDK المناسبة.
- إذا ظهر خطأ متعلق بإصدار Gradle/AGP، أرسل صورة الخطأ لنضبط الإصدارات حسب نسخة AndroidIDE الموجودة عندك.
